# yamvp.ru (Tilda, archived)

The yamvp.ru team page ("Freelancer"), exported from Tilda (project "ivntl",
page 30964129). Kept on this branch for later work alongside itolmach.com;
nothing here is linked from `main`.

- `page30964129.html` is the page as Tilda exported it; `index.html` is a copy
  so the folder serves as a site. Everything else is Tilda's own export.
- Still external, as exported: Tilda's CDN scripts and stats.
- yamvp.ru itself does not resolve at present (no DNS delegation), so the
  registration needs checking at its registrar before it can point here.

To view: `npx http-server . -p 8000`, then open http://localhost:8000.
